# Naresh BM — Portfolio

A responsive student portfolio for Naresh BM, a first-year Mechanical Engineering student at HKBK College of Engineering.

## GitHub Pages
1. Put `index.html` and `style.css` in the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Tap **Save**.

The site contains no invented skills, certificates, projects, email address, GitHub account or LinkedIn account. Those can be added later when Naresh has them.
